# Онлайн-запись: функция в Yandex Cloud

Сайт (GitHub Pages) показывает календарь и форму, а эта функция:
- читает Яндекс Календарь и отдаёт свободное время (только «свободно/занято», без имён);
- по заявке создаёт в календаре событие «Заявка: услуга — имя» со статусом «под вопросом»
  и шлёт сообщение в Telegram.

Услуги, длительности, минимальный срок до записи и запас на дорогу — в начале `booking.py`.
Проверка логики без Яндекса: `python3 backend/test_booking.py`.

## Настройка (один раз)

1. **Пароль приложения Яндекса.** id.yandex.ru → Безопасность → Пароли приложений →
   «Календарь (CalDAV)» → создать. Сохраните пароль — он показывается один раз.
2. **Бот в Telegram.** @BotFather → `/newbot` → получите токен. Напишите своему боту
   любое сообщение, откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
   `"chat":{"id": ...}` — это ваш chat id.
3. **Функция.** console.yandex.cloud → Cloud Functions → «Создать функцию» `booking`:
   - среда выполнения **Python 3.12**, способ — ZIP-архив (`booking.py` + `requirements.txt`);
   - точка входа `booking.handler`, таймаут 15 с, память 256 МБ;
   - переменные окружения:

     | Переменная | Значение |
     |---|---|
     | `YANDEX_LOGIN` | логин Яндекса, например `name@yandex.ru` |
     | `YANDEX_APP_PASSWORD` | пароль из шага 1 |
     | `CALENDAR_NAME` | название календаря; пусто — первый календарь |
     | `TG_BOT_TOKEN` | токен из шага 2 |
     | `TG_CHAT_ID` | chat id из шага 2 |
     | `ALLOWED_ORIGIN` | `https://limegrip.github.io` |
     | `BUFFER_MIN` | запас на дорогу в минутах, по умолчанию `60` |

   - в «Обзоре» включите **«Публичная функция»** и скопируйте ссылку для вызова.
4. Вставьте ссылку в `index.html`: `<section class="booking" id="booking" data-api="ССЫЛКА">`.

## Переключение на календарь Насти

Поменять `YANDEX_LOGIN`, `YANDEX_APP_PASSWORD` (пароль приложения из её аккаунта),
при необходимости `CALENDAR_NAME` и `TG_CHAT_ID`. Код и сайт трогать не нужно.

## Как Настя пользуется

- Выходной или отпуск — событие «на весь день» в календаре: день пропадает с сайта.
- Запись открыта круглосуточно — часы, когда Настя не работает (например, ночь), тоже
  закрываются событием в календаре, можно повторяющимся.
- Событие с пометкой «свободна» (не занята) запись не блокирует.
- Заявка приходит в Telegram и появляется в календаре; после созвона Настя правит или
  удаляет событие, и сайт сразу это учитывает.
