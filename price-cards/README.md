# Карточки прайса для соцсетей

`price.html`, `lessons.html` и `wedding.html` (свадебные пакеты) — вёрстка сторис 1080×1920 в стилистике
сайта (та же палитра, Cormorant Garamond и Manrope). Рядом лежат готовые
`price.jpg`, `lessons.jpg` и `wedding.jpg` — их можно выкладывать как есть.

Цены поменялись — правим HTML и перерисовываем:

```bash
node render.mjs
```

Скрипт поднимает headless Chrome, снимает все страницы и пересобирает JPEG.
Нужен Google Chrome. Шрифты локальные — из `../fonts/`, как на сайте.

Цены на самом сайте живут в разделе «Услуги» (`index.html`, блок `.pricing`
и полоса доплат сразу за секцией) — их надо править отдельно.
