# Карточки прайса для соцсетей

`price.html` и `lessons.html` — вёрстка двух сторис 1080×1920 в стилистике
сайта (та же палитра, Cormorant Garamond и Manrope). Рядом лежат готовые
`price.jpg` и `lessons.jpg` — их можно выкладывать как есть.

Цены поменялись — правим HTML и перерисовываем:

```bash
node render.mjs
```

Скрипт поднимает headless Chrome, снимает обе страницы и пересобирает JPEG.
Нужны Google Chrome и интернет: шрифты грузятся с Google Fonts, как на сайте.

Цены на самом сайте живут в разделе «Услуги» (`index.html`, блок `.pricing`
и полоса доплат сразу за секцией) — их надо править отдельно.
